# Matrimony-Site
This project is a Matrimony Website developed using PHP and MySQL as part of a 3rd Year DBMS Mini Project. The goal of this system is to provide a secure and efficient online platform where users can create profiles, set match preferences, communicate with potential matches, and manage matrimonial interactions digitally.
The system is designed to demonstrate practical implementation of database design, normalization, relationships, and CRUD operations, along with real-world web application functionality.

✨ Features

1) User Registration & Login
Secure authentication system for users.

2) Profile Management
Users can create, view, and edit personal profiles.

3) Match Preferences
Search and filter profiles based on preferences like age, location, and other criteria.

4) Messaging System
Allows users to communicate securely with matched profiles.

5) Admin Panel
Admin can manage users, profiles, and monitor platform activity.

6) Statistics & Reports
Displays basic statistics such as number of users, profiles, and interactions.

🛠️ Technology Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Server: Apache (XAMPP / WAMP)

🗂️ Database Concepts Used
Relational database design
Primary & foreign keys
Normalization
SQL queries (SELECT, INSERT, UPDATE, DELETE)
User authentication & role management

🎯 Project Objective
To apply DBMS concepts in a real-world application
To design an efficient and scalable database
To provide hands-on experience with full-stack web development

This project is suitable for:
